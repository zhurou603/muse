# S5 训练数据与预处理

## 1. 合规边界

S5 只使用三类数据：

1. **官方 A-train**：仅 `manifest.json → files.train → train.jsonl`，允许训练 Encoder。加载器强制 `muse.release.v2`，并核对 78 个 source、90 个任务、60,868,251 条记录、70,909,310 条观测。
2. **官方明确允许的 aux**：允许训练 Encoder，但不计分。任务身份是 `source::name::unit`，同名不同单位不得合并。
3. **既有外部无标签语料**：只保留输入 SMILES/PSMILES/序列及输入可计算描述符，不读取外部性质标签，不加载任何第三方预训练权重。

validation/test 标签不参与训练、统计、归一化或选模。validation/test 输入仅用于去泄漏指纹。S5 不重新引入 UniParc，不下载新的有标签数据库，不改变 tokenizer 或模型规模。

## 2. 官方 A-train

统一格式为 `muse.final.v1` JSONL，每行有全局唯一 `id`、`sample_type`、`inputs`、`external_inputs`、`labels`。实际 subset 和任务名以官方 manifest 为唯一权威。

| 领域 | 数据集 | S5 用途 | 读取位置 |
|---|---|---|---|
| 小分子 | FreeSolv | 水合自由能 train 监督 | 官方 manifest 对应 subset 的 `train.jsonl` |
| 小分子 | TDC ADMET（22 subsets） | ADMET train 监督，逐 source 轮换 | 同上 |
| 小分子 | GEOM-Drugs | train 任务与官方构象/能量 aux 分开读取 | A-train 与 aux 不混文件 |
| 小分子 | QMugs | 量子性质 train 监督 | `QMugs/qmugs/train.jsonl` |
| 小分子 | QM9 | 量子性质 train 监督 | `QM9/qm9/train.jsonl` |
| 聚合物 | PolyGraphMT | BANDGAP/HOMO/LUMO/MU 电子任务 replay | 四个官方 subset |
| 聚合物 | Aldeghi-Coley-Copolymer | EA/IP | 官方 `vipea` subset |
| 聚合物 | TransPolymer | Egb/Egc/Eea/Ei；不在 S5 重押 EPS/Eea/Nc 救头已解决项 | 官方 subsets |
| 聚合物 | Polymer Genome 2016 | HSE06/rPW86 两个电子带隙，每 20 步一个专属槽位 | 两个 DFT subset |
| 有机晶体 | OMC25 | 沿用 S3 晶体管线；A-train 不与 7M frame 缓存混读 | 官方结构和 S3 缓存 |
| 生物 | DBAASP | 原样复用唯一已证实有效的 S2 treatment | `dbaasp_v4/target_activity` |
| 生物 | PEER | 官方 subsets 轮换，所有任务头按 source 读取 | 官方 manifest |
| 生物 | CATH | 官方 source 轮换，分类编码沿用官方 scorer | 官方 manifest |

记录内多观测回归的新默认是 **median**。对同一记录的常数预测，MAE 的记录内最优常数是中位数；旧 mean 文件不覆盖。分类仍用官方 JSON 类别编码；逐残基任务检查标签长度与 token 对齐。S5 目标统计是 train-only median/MAD，MAD 退化时依次回退 std、1.0，Encoder 回归头使用 Huber。

## 4. 外部无标签语料

| 语料 | 现役记录数 | 原始文件血缘 | 处理与用途 | 版本/许可证状态 |
|---|---:|---|---|---|
| PubChem | 40,000,000 | `pubchem_cid_smiles.gz` | RDKit 清洗、固定种子 42 蓄水池抽样、分子指纹去泄漏、208D、MLM/MTR | 抽样版本、原始 hash、下载日期待原仓库补证 |
| ChEMBL | 2,870,569 | `chembl_37_chemreps.txt.gz` | 同上，不抽样换版 | ChEMBL 37 已确认；许可证/hash 待补证 |
| PI1M | 995,542 | `PI1M_v2.csv` | PSMILES 去泄漏、固定 5 视图、208D、MLM/MTR | 原仓库写明 academic purpose only；raw hash 待补证 |
| UniRef50 | 53,624,246 | `uniref50.fasta.gz` | 氨基酸/长度过滤、10-mer 去泄漏、长短序列 MLM | release 必须按既有文件补证，不能用最新版替代 |
| PDB SEQRES | 630,326 | `pdb_seqres.txt.gz` | 同上，长短 PDB replay | 快照日期、许可证/hash 待补证 |

描述符是输入可计算知识：RDKit `Descriptors._descList` 208 维；PSMILES 沿用 `smiles.replace("*", "C")` 端基约定；NaN/Inf 用列中位数修补，全列无效为 0；keys 与清洗语料逐行对齐。归一化常数列 mask 为 false。

`config/external_provenance.yaml` 是待补证模板，不是完成的许可证证明。最终复现前运行外部审计，任何 `待核验` 都返回非零。

## 5. 下载、校验与安全解包

```bash
export REPO_ROOT=/path/to/项目根目录
cd "$REPO_ROOT"
bash scripts/download_official.sh /data/downloads/muse-a
python3 scripts/safe_extract.py /data/downloads/muse-a/MUSE-A_jsonl.tar.zst /data/unpacked
# 对其余 tar.zst 逐个执行；每个包生成独立目录，存在即拒绝覆盖。
```

官方包必须先通过 `MUSE-A_SHA256SUMS.txt`。安全解包拒绝绝对路径、`..`、符号/硬链接、设备文件、重复文件和目录覆盖。

`download_external_reference.sh` 只下载参考副本。PubChem、UniRef50、PDB 是滚动快照，PI1M master 也应固定 commit；参考副本不得直接覆盖现役语料。

## 6. 既有预处理复现命令

以下命令对应现有实现；若现役文件已齐全，不要为“再跑一遍”覆盖它们。先备份原日志、配置和 hash。

```bash
export PYTHONPATH="$REPO_ROOT/code:$REPO_ROOT/code/model_design"
cd "$REPO_ROOT"

# validation/test 仅提取输入指纹，不读取标签。
python3 code/muse/pretrain/build_fingerprints.py

# 分子清洗与去泄漏；pubchem 的 40M 为固定种子抽样。
python3 code/muse/pretrain/dedup_molecules.py pubchem --sample 40000000 --workers 64
python3 code/muse/pretrain/dedup_molecules.py chembl --workers 64
python3 code/muse/pretrain/dedup_molecules.py pi1m --workers 64

# 序列清洗与去泄漏；正式复现必须沿用原日志中的过滤参数。
python3 code/muse/pretrain/dedup_sequences.py uniref50 --workers 64 --seed 42
python3 code/muse/pretrain/dedup_sequences.py pdb --workers 64 --seed 42

# 208D 描述符，支持 memmap、checkpoint 和断点续跑。
python3 code/muse/pretrain/compute_descriptors.py --input data/pretrain/corpora_clean/pubchem.tsv --name pubchem --total-lines 40000000 --workers 96
python3 code/muse/pretrain/compute_descriptors.py --input data/pretrain/corpora_clean/chembl.tsv --name chembl --total-lines 2870569 --workers 96
python3 code/muse/pretrain/compute_descriptors.py --input data/pretrain/corpora_clean/pi1m.tsv --name pi1m --total-lines 995542 --workers 96

# 语料 offsets、PI1M 五视图、天然短肽索引。
python3 -m muse_encoder.pretrain.prepare_indexes --workers 32
python3 -m muse_encoder.pretrain.prepare_natural_peptides --max-residues 50

# 官方 aux 索引与 train-only 允许标签统计。
python3 -m muse_encoder.pretrain.prepare_aux_indexes --sources geom_drugs qmugs qm9 pubchemqc pcqm4v2 megascale_d1 megascale_d23 dbaasp_hemo dbaasp_nonmic
python3 -m muse_encoder.pretrain.compute_target_stats --sources geom_drugs qmugs qm9 pubchemqc pcqm4v2 megascale_d1 megascale_d23 dbaasp_hemo dbaasp_nonmic
```

MTR 全局归一化沿用 `DescriptorStore` 和 `compute_global_norm`，输入只含 pubchem/chembl/pi1m 描述符，输出 `data/pretrain/targets/mtr_norm.json`。DBAASP 仍运行原 `prepare_dbaasp_pilot.py`，保留其 train-only MIC、log1p(MIC)、12 个序列描述符、去污染 replay 和 manifest。

## 7. S5 新增准备步骤

```bash
export REPO_ROOT=/path/to/项目根目录
export PYTHONPATH="$REPO_ROOT/code:$REPO_ROOT/code/model_design"
python3 -m muse_encoder.s5.prepare_data \
  --config "$REPO_ROOT/code/model_design/configs/s5_continuous.yaml" --recompute-targets
```

该命令单进程完成：

- 由课程反推实际 official sources；
- 生成 `s5_a_train_targets.json`，不覆盖旧 mean 目标；
- 顺序建立所有 A-train offsets/metadata，避免 DDP 建索引竞争；
- 对 official train、aux、外部清洗语料、描述符、索引、排除 hits、replay、OMC25 资产计算 SHA256；
- 写出 `s5_data_manifest.json`，训练启动时小文件全部重 hash，大文件核对字节数；`--full-hash` 可全量复核。

PI1M 近似图审计：

```bash
python3 -m muse_encoder.s5.audit_featurization \
  --source pi1m --limit 10000 \
  --output data/pretrain/audit/s5_pi1m_featurization.json \
  --max-degraded-fraction 0.05
```

审计按全库均匀 row/view 抽样，分别统计 degraded、truncated、error 和 token 长度。阈值是明确的工程门，不是“近似图可接受”的科学结论；超过阈值应停止并检查，不得把 strict=False 当长期静默回退。
