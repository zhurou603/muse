# MUSE 赛题深度调研与方案设计：四域 SOTA、数据来源、预训练 Mask 算法与统一 Encoder 架构

> 面向赛题「跨模态科学数据统一表征与多尺度融合」（OpenCompass 2026 以赛代评，MUSE 赛道）。
> 本文完成四件事：(1) 小分子、聚合物、有机晶体、生物大分子四个领域的 SOTA 深度调研；(2) 可用数据来源盘点与数据规划；(3) 预训练 mask 算法谱系调研与本赛题的预训练算法设计；(4) 符合赛题全部硬约束（从头训练、统一维度 D、冻结共享、≤100K MLP）的统一 Encoder 架构设计。全文精读并总结了 11 篇核心论文（超过题面要求的 4 篇），所有关键数据均附原始出处。

## 执行摘要

本赛题的本质是一场**"表征工程"竞赛**：Encoder 冻结共享、下游只允许 ≤2 层、≤100K 参数的 MLP 探针，且 B 榜考的是"冻结表征在**未见性质**上的泛化"。因此方案设计的唯一评价标准是——**预训练后表征中性质信息的线性可读性**，而不是任何单一任务的拟合精度。基于对四域 SOTA 与预训练文献的系统调研，本报告给出如下核心结论与设计：

1. **SOTA 格局**：小分子域的实证最强路线是 Uni-Mol2 式"掩码原子 + 坐标去噪"3D 预训练（QM9 平均提升 27%）与 CheMeleon/ChemBERTa-2 式"描述符多任务回归（MTR）"——后者在冻结/小数据设定下更稳；聚合物域是 PI1M 语料上的 MLM（TransPolymer、polyBERT）；晶体域是 OMC25 能量/力/应力监督的 MLIP 路线（UMA/eSEN、DPA-2、JMP）；蛋白域是 UniRef50 上的残基 MLM（ESM-2）。
2. **数据规划**：以官方 A 榜任务数据与辅助标签（OMC25 受力/应力 2,511 万帧、GEOM 能量 3,231 万构象、QMugs 37 个字段 191 万构象等）为主力监督源，叠加公开无标签语料（PubChem/ZINC、PI1M、UniRef50、PDB 等）做覆盖扩张；全部外部数据登记进 `data_manifest.jsonl`，并对 A 榜验证/测试集做指纹级去泄漏。
3. **预训练算法**：六组损失的课程式组合——掩码重建（MLM/掩码原子）、坐标去噪（score matching）、能量/力/应力回归、描述符蒸馏（MTR）、2D↔3D 跨视图对比、辅助标签多任务；A 榜标签仅以 ≤5% 权重轻量混入。
4. **模型架构**：从头训练的"四域前端 + 共享 Transformer 主干（几何感知注意力 + MoLE 专家层）+ 统一 D=1024 读出"，总规模约 3 亿参数，单一 checkpoint 服务全部 90 个子任务与逐残基输出，满足冻结共享、统一维度、批次无关等全部约束。

## 1. 赛题约束解读：设计空间由五条硬规则决定

在展开 SOTA 调研之前，必须先钉死约束，因为赛题的几条规则直接否决了一批"想当然"的方案。以下全部出自赛题官方文档与 Q&A。

**规则一：Encoder 必须从头训练。** Q&A（2026-10-10）明确答复："如果不是参赛队伍自己训练的公开预训练模型则不能使用，需要从队伍从头训练全部 encoder 参数"（[赛题 Q&A](https://opencompass.org.cn/nextgenai-scicomp26/qa)）。这意味着直接加载 Uni-Mol2、ESM-2、UMA 的公开权重是违规的——它们只能作为**架构与训练方法的蓝本**，不能作为权重起点。这一条是本方案与"搬开源模型"路线的分水岭，也直接决定了算力预算和数据规划的形态：所有能力必须来自自己声明的数据和自己的训练流程。

**规则二：统一 Encoder、统一维度、冻结共享。** 参赛者提交**一个** Encoder，"所有领域输出同一维度 D 的表征"（2026-10-19 Q&A 修正：`embedding_dims` 改为单一 `embedding_dim`）；评测中 Encoder 冻结共享，不允许针对单个任务微调；"是否在不同任务中加载了实质上不同的 Encoder 主体"是复现审查重点（[赛题详情](https://opencompass.org.cn/nextgenai-scicomp26/detail/muse)）。允许的灵活性在于输入处理："同一领域的所有子集使用同一套处理，不得按数据集名、子集名或记录 id 分支"——即**领域级的前端差异是合法的**，但同一领域内部不得分叉。

**规则三：下游只有轻量 MLP。** 每个子任务一个 MLP，`Linear → [激活] → Linear` 最多两个线性层，参数量 ≤100,000；表征标准化等仿射操作必须折进第一层或放进 Encoder；阈值、校准、检索、残差、LayerNorm 等后处理一律禁止（[赛题详情](https://opencompass.org.cn/nextgenai-scicomp26/detail/muse)）。若 D=1024、隐藏维 48，回归头参数量约 49K，留有充分余量；这也说明 D 不宜过大。

**规则四：数据合规。** 预训练只允许"公开无标签数据或自建无标签数据"，有标签数据仅可用 A 榜训练集；官方辅助标签（`aux_labels/`）明确"可选择用于训练 Encoder"，且不覆盖 A 榜验证/测试集物质；外部数据须以机器可读清单登记来源、许可、hash 与用途。禁止隐藏测试标签、测试集等价标签、外部数据库查询目标性质与测试集反向工程。

**规则五：完全可复现。** 需提交 Dockerfile、训练代码、配置、随机种子、起点权重（从零训练为空）、可续跑中间 checkpoint、日志与算力说明，主办方会在一周内重跑训练核验（[赛题 Q&A](https://opencompass.org.cn/nextgenai-scicomp26/qa)）。算力环境为 H200、可多机，预训练算力暂不设上限，但须申报一周内完成完整训练的算力预估。

**评测结构**决定优化目标：回归按 `clip(1−MAE/B_t,0,1)`、分类按 `clip(2·AUC−1,0,1)` 归一化后三层等权（子任务→数据集→领域→总分 ×100）。其推论是：**四个领域等权，任何一个领域塌掉，总分上限直接减 25 分**；小数据集（FreeSolv 0.6K、Polymer Genome 1.1K）与大数据集（GEOM 32M、OMC25 25M）在各自领域内等权，小数据任务的探针方差控制（嵌套 CV、多种子合并为更宽 MLP——规则明确允许）同样是得分点。

## 2. 四大领域 SOTA 调研

### 2.1 小分子：3D 预训练与描述符监督是当前的两条实证主线

小分子是本赛题最大的领域（5 个数据集、36 个子任务、约 3,400 万条记录，其中 GEOM-Drugs 占 3,200 万）。该领域的表征学习沿三条技术线演进，且都在本赛题的输入形态（SMILES / 3D 构象）上有直接对应。

**第一条线：SMILES 序列模型（1D）。** ChemBERTa-2 用 RoBERTa 架构在 7,700 万条 PubChem SMILES 上对比了两种预训练目标：标准 MLM（随机掩码 15% token 做交叉熵重建）与多任务回归 MTR（预测 200 个由 RDKit 计算的分子性质，标签做均值归一化）。结果是**在全部下游任务上 MTR 均优于 MLM**，且数据量从 5M 扩到 77M 使预训练 loss 下降 25–35%，但下游收益并非单调——个别任务上 77M 反而不如 5M，提示"预训练 loss 下降 ≠ 下游表征变好"（[ChemBERTa-2, arXiv:2209.01712](https://ar5iv.labs.arxiv.org/html/2209.01712)）。IBM 的 MoLFormer 把同一思路推到 11 亿分子（PubChem+ZINC），用线性注意力 + RoPE 把训练 GPU 需求从约 1000 卡降到 16 卡，词表 2,362 个化学 token、序列截断 202（覆盖 99.4% 分子）（[MoLFormer, Nature MI 2022](https://hunterheidenreich.com/notes/chemistry/molecular-representations/encoders/molformer/)）。

**第二条线：3D 几何预训练（当前最强实证）。** Uni-Mol2 用"原子轨 + 原子对轨"的双轨 Transformer 同时编码原子特征、键/最短路/欧氏距离对特征与 3D 坐标，在 8.84 亿构象（7,300 万骨架，ETKDG+MMFF 生成）上预训练到 11 亿参数（64 层、hidden 1536），预训练任务为掩码原子预测（15%）+ 坐标去噪（高斯噪声，且以 50% 概率同时掩掉原子/键/距离特征增加难度），总损失 `L = L_atom + L_coor + L_dist`；为平衡骨架长尾分布采用温度采样（τ=0.005）。1.1B 版本在 QM9 上平均提升 27%、COMPAS-1D 提升 14%，并首次给出分子预训练的 scaling law（[Uni-Mol2, arXiv:2406.14969](https://arxiv.org/abs/2406.14969)）。QM9、QMugs、GEOM 正是本赛题 SM-A-3/4/5 的数据来源，这条线与本赛题小分子域**完全同构**。其后续 Uni-Mol3 进一步引入多尺度 Mol-Tokenizer 把 1D/2D/3D 信息量化为离散 token，做"分子预训练→反应预训练"的两级课程（[Uni-Mol3, arXiv:2508.00920](https://arxiv.org/html/2508.00920v1)），其分层 tokenization 思想对本方案的"统一词表"设计有参考价值。

**第三条线：描述符/知识注入监督（冻结探针设定下最稳）。** CheMeleon 用约 1 千万参数的有向消息传递网络（D-MPNN）直接回归 Mordred 包计算的确定性分子描述符，在 Polaris 58 个基准上取得 75–79% 胜率（超过随机森林的 68%），在 MoleculeACE 上胜率 97%（[CheMeleon, arXiv:2506.15792](https://arxiv.org/abs/2506.15792)）。它的方法论启示对本赛题尤其重要：**描述符是由输入分子确定计算的，无实验噪声、无外部标注、无泄漏风险，却能把"化学家几十年积累的性质先验"显式写进表征**——这正是冻结表征 + 线性探针协议最需要的性质。同一方向还有 Mol-JEPA：不给分子做数据增强，而是**掩码"模态"**（结构、描述符、生物活性、其他模型嵌入等 14 种视图），在潜空间预测被掩视图的嵌入，配 SIGReg 防坍塌；4.66M 化合物、14 模态，模态越多下游越好（[Mol-JEPA, arXiv:2608.22642](https://arxiv.org/html/2608.22642v4)）。此外 3D Infomax / GraphMVP 证明了 2D↔3D 互信息最大化的价值：让同一分子的 2D 图视图与 3D 构象视图在表征空间对齐，可把 3D 预训练的红利迁移到只有 SMILES 输入的任务（本赛题 SM-A-1/2 正是纯 SMILES）（[3D Infomax, arXiv:2110.04126](https://arxiv.org/html/2110.04126v4)）。

**对本赛题的映射**：SM-A-1（FreeSolv 水合自由能）、SM-A-2（TDC ADMET 22 项）是纯 SMILES 任务，受益于序列预训练 + 描述符蒸馏 + 2D↔3D 对齐；SM-A-3/4/5（GEOM/QMugs/QM9 的构象能量与 DFT 性质）带 3D 构象输入，是坐标去噪 + 能量监督的主场。一个必须警惕的实证警告：系统性评测发现**冻结嵌入常常打不过 ECFP 指纹 + 经典学习器**（[ProgDrug 综述](https://progdrug.com/de/blog/machine-learning-admet-prediction-methods-tools/), [Lzicar](https://mireklzicar.com/blog/embeddings-fingerprints/)），贝叶斯检验的基准研究也采用"冻结嵌入 + 固定探针头"协议来严格比较表征质量（[arXiv:2508.06199](https://arxiv.org/html/2508.06199v4)）。这印证了本赛题"纯自监督掩码不够、必须注入描述符与能量监督"的判断。

### 2.2 聚合物：PI1M 语料 + MLM 是已被反复验证的范式

聚合物域有 4 个数据集（PolyGraphMT 20 子任务、共聚物 EA/IP、TransPolymer 10 性质、Polymer Genome 晶体性质），输入为 PSMILES（以 `*` 标记聚合位点的重复单元 SMILES）、单体 SMILES+组成比，或晶体 CIF。

**TransPolymer** 是该方向的开创性工作：RoBERTa 架构 + 化学感知 tokenizer，在 PI1M 数据库约 100 万条 PSMILES（数据增强到约 500 万条）上做 MLM 预训练，在电导率、带隙、电子亲和能、介电常数、折射率、结晶倾向、OPV 效率等 **10 个基准上全部达到 SOTA**，相对此前最优基线 RMSE 平均下降 7.70%、R² 提升 0.11；相对不预训练的同款模型，RMSE 下降 18.5%（[TransPolymer, arXiv:2209.01307](https://arxiv.org/abs/2209.01307)）。其消融证明三点贡献来源：大规模无标签 MLM 预训练、encoder 与回归头联合微调、数据增强。注意本赛题 PO-A-3 的数据来源**就是 TransPolymer 论文的十个数据集**——这意味着该论文的训练配方（增强方式、tokenizer、掩码率）就是该数据集的原生 SOTA 配方，可直接借鉴。

**polyBERT** 走了更大语料的路线：用 SentencePiece 在 1 亿条假想 PSMILES（8,000 万训练）上训练 DeBERTa（12 层、768 维），15% 掩码率，指纹取最后层 token 平均；在 29 种聚合物性质上与手工 Polymer Genome 描述符打平（平均 R² 0.80 vs 0.81），但推理快约 215 倍（[polyBERT, arXiv:2209.14803](https://ar5iv.labs.arxiv.org/html/2209.14803)）。**PI1M 本身**由生成模型在 PolyInfo 的 1.2 万真实聚合物上训练后采样约 100 万条虚拟聚合物构成，化学空间覆盖与 PolyInfo 相似但更致密，是聚合物域预训练的标准无标签语料（[PI1M, JCIM 2020](https://pubs.acs.org/doi/10.1021/acs.jcim.0c00726)）。

**对本赛题的映射**：聚合物是"改造成本最低、等权收益最高"的领域——PSMILES 可直接走 SMILES 管线（`*` 作为特殊 dummy 原子 token），预训练语料（PI1M）公开无标签、许可清晰；PO-A-2 的"单体 SMILES + 组成比"可在 Encoder 内部做组成加权组合（属于输入处理，不违反表征约束）；PO-A-4 是晶体 CIF 输入，归入晶体前端处理。PO-A-1 PolyGraphMT 的 DFT/MD/基团贡献性质提示：把基团贡献式描述符蒸馏扩展到重复单元，是提升聚合物域线性可读性的低成本手段。

### 2.3 有机晶体：能量/力/应力监督的 MLIP 范式已成熟，且官方数据与之同源

晶体域在本赛题只有 OC-A-1 一个数据集（OMC25，DFT 总能量回归，2,500 万条），但它是全赛题第二大单数据集，且 PO-A-4 也是晶体输入。该领域过去三年的 SOTA 演进非常快，已形成清晰的"通用原子模型"范式。

**数据侧**，OMC25 由 Meta FAIR 于 2025 年发布：超过 2,700 万个分子晶体结构（发布的训练+验证切分为 26,257,042 帧、218,841 个初始堆积、46,870 个分子，来自 OE62），由 Genarris 3.0 随机生成堆积、PBE+D3（VASP）弛豫轨迹产生，每帧带总能量、逐原子受力与晶胞应力，CC-BY-4.0 许可（[OMC25, arXiv:2508.02651](https://arxiv.org/abs/2508.02651), [Matbench Discovery 数据卡](https://matbench-discovery.materialsproject.org/data/omc25)）。本赛题 OC-A-1 与其**同源同流程**，且官方辅助标签直接给了 2,511 万帧逐原子受力与应力——这是赛题设计者留下的最大"免费午餐"：晶体域的预训练监督信号已经备好，问题只在于架构能不能吃进去。

**架构侧**，当前通用原子模型的代表是 Meta 的 UMA：以 eSEN 为骨干（等变平滑能量网络，SO2 卷积 + 保守力场，力 = 能量对坐标负梯度，保证势能面光滑），训练数据为 OC20/OMat24/ODAC/OMC25/OMol25 合计约 5 亿结构、超 300 亿原子；核心创新是 **MoLE（Mixture of Linear Experts）**——把 MoE 思想用于线性层，UMA-M 总参数 14 亿但每个结构只激活约 5,000 万，按 DFT 任务/电荷/自旋条件路由，实现跨域知识迁移而不牺牲推理速度；单模型无需微调即可持平或超过各领域专用模型（[UMA, arXiv:2506.23971](https://arxiv.org/abs/2506.23971), [MLIP Hub](https://www.mliphub.com/)）。训练工程上，eSEN/UMA 的两阶段配方值得直接借用：**先用直接力预测（快）训练，再接保守力微调，总训练时间比从头保守训练省约 40%**（[eSEN, arXiv:2502.12147](https://arxiv.org/pdf/2502.12147), [Rowan](https://www.rowansci.com/blog/exploring-open-molecules-2025)）。

**多数据集联合预训练的有效性**由两条独立路线验证：CMU/Meta 的 JMP 在 OC20、OC22、ANI-1x、Transition-1x 约 1.2 亿体系上联合预训练 GemNet-OC，证明跨数据集预训练对下游微调普遍有益（[JMP, MLIP Hub](https://www.mliphub.com/)）；DeepModeling 的 DPA-2 用多任务策略在 18 个数据集、73 种元素上预训练，使下游任务数据需求降低约两个数量级（[DPA-2, arXiv:2312.15492](https://arxiv.org/html/2312.15492v1)）。OMat24 的工作还澄清了一个数据策略细节：对大规模高多样性数据（如 OMat24/OMC25），额外的去噪结构增强（DeNS）无收益甚至有损，**数据多样性本身已足够**；它只在小数据（MPtrj）上有用（[OMat24, arXiv:2410.12771](https://arxiv.org/html/2410.12771v2)）。

**对本赛题的映射**：晶体前端需要 PBC 图构建（跨晶胞邻居搜索、多晶胞截断）+ 晶胞/空间群嵌入，监督为能量/力/应力三件套。力是逐原子监督，单帧信号量是分子级能量的数十倍，配比上力损失权重需显著高于能量（社区惯例约 10–100:1）。由于 OMC25 有 2,500 万帧而预训练窗口有限，子采样 500–800 万帧 + 按能量/受力离群度过滤（参考 sAlexandria 的过滤规则）是现实的算力折中。

### 2.4 生物大分子：残基级 MLM 是唯一被大规模验证的路线

生物大分子域有 3 个数据集（DBAASP 肽 MIC 回归 4.8 万条、PEER 16 子任务 65 万条、CATH 四级分类 60.1 万条），输入为氨基酸序列、序列对、蛋白+配体 SMILES，且包含**逐残基分类**任务——要求 Encoder 输出 `tokens.npy` 逐 token 表征，这一条直接否决了"分子级池化-only"的架构。

**ESM-2 是该域的事实标准范式**：标准 MLM（随机选位置换成 mask token，最大化真实氨基酸的对数似然），训练数据为约 4,300 万 UniRef50 聚类（源自 1.38 亿 UniRef90 序列，实际见到约 6,500 万条不同序列），参数从 8M 到 15B，验证困惑度从 10.45 降到 6.37，且注意力中自发涌现出残基接触图结构——规模越大结构理解越深（[ESM-2/ESMFold, bioRxiv](https://www.biorxiv.org/content/10.1101/2022.07.20.500902v2.full.pdf), [Lin 博士论文](https://cs.nyu.edu/media/publications/ZemingLin-phd.pdf)）。但**从头训练时的数据-参数配比有已知陷阱**：Profluent 的 compute-optimal 研究用 1,940 亿氨基酸 token（UniRef50/S 54M 序列/15.2B token、UniRef90/50 102M/37.8B、ColabFoldDB 575M/103B 等按 8.5%/19.5%/19.5%/52.5% 配比采样）发现，MLM 目标在 3B 参数处出现严重过拟合（双向注意力容量大、记忆训练集快），150M 则泛化不足——**对本方案 3 亿参数级的主干，蛋白序列 MLM 是安全的规模区间**（[Compute-Optimal PLM, arXiv:2411.02142](https://arxiv.org/html/2411.02142v1)）。

**评测侧**，本赛题 BIO-A-2 的数据来源 PEER 基准（NeurIPS 2022）覆盖蛋白功能、定位、结构、相互作用、亲和力五类任务，其官方结论是"大规模预训练蛋白语言模型在多数任务上最优，且多任务联合训练进一步提升"（[PEER, NeurIPS 2022](https://neurips.cc/virtual/2022/events/datasets-benchmarks-2022)）——这直接支持"统一 Encoder + 多任务探针"的赛题设定。BIO-A-3 的 CATH 是按 Class/Architecture/Topology/Homology 四级层次分类的结构域数据库（[CATH 综述, arXiv:2307.02171](https://arxiv.org/pdf/2307.02171.pdf)），序列→四级分类本质上是"远程同源识别"，对表征的全局语义要求高。

**肽域需要单列一段**，因为它恰好落在"小分子"与"蛋白"两条技术线的接缝上，且 DBAASP 中含有大量非天然氨基酸修饰的肽。PepLand（KAUST/吉林大学）是目前该细分方向最系统的预训练工作，四点结论全部与本赛题直接相关（[PepLand, arXiv:2311.04419](https://arxiv.org/abs/2311.04419)）：其一，**肽的随机掩码是退化的**——肽键（酰胺键）原子在肽中占比很高，随机掩码会让大部分预测目标退化成"猜肽键原子"这种送分题；其消融显示按结构语义掩码显著更优，非天然肽亲和力任务上 FragmentMasking 的 Spearman 达 0.767，而 RandomMasking 仅 0.678。其二，**粒度决定性能**：纯原子级分子图在肽上最差（图过大导致消息传递与池化丢信息），"保留酰胺键 + 对超大侧链用 BRICS 再切分"的 AdaFrag 片段策略词表仅 258 项、恢复率 97.52%，在多数任务上最优——肽需要"原子—片段"多粒度异构图，而非纯原子图。其三，**两步课程预训练**（先在约 800 万条 ≤50 残基的天然肽 UniProt 子集上收敛，再在 8,977 条非天然肽上续训）在全部五个基准上优于单步混合训练。其四，**读出方式有讲究**：GRU 池化在所有下游任务上优于 mean/max 池化（非天然 CPP 任务 Spearman 0.742）；且 PepLand 的评测协议恰是"冻结表征 + 两个线性层"，与本赛题 MLP 协议同构，是"冻结探针"证据链的直接补强。值得注意的是，在纯天然肽任务上 15B 参数的 ESM-2 仍优于 PepLand（800 万肽 vs 4,500 万蛋白序列的规模差距），而 PepLand+ESM 融合特征最强——这支持本方案"序列前端与原子级前端并存"的架构，而不是二选一。

**对本赛题的映射**：序列前端 = 残基 tokenizer（20 种标准氨基酸 + 特殊残基 + mask/CLS 等特殊符号，约 26–30 词表）+ RoPE，输出同时保留池化表征与逐 token 表征。**肽记录的处理规则由 PepLand 的结论修订**：DBAASP 中含非天然氨基酸/HELM 描述的肽，序列 tokenize 不可行时走原子级前端（转 SMILES/结构图），并在预训练掩码上启用肽感知策略（侧链/片段掩码，见 §5.1）；两条前端共享同一主干，仍是同一 Encoder 主体。预训练语料用 UniRef50（无标签、可自由下载），肽子域参照 PepLand 做"天然肽 → 非天然肽"两步课程；官方辅助标签里的 MegaScale 261 万序列稳定性数据可作为"有监督但非下游等价"的补充监督（注意 MegaScale 是 ΔΔG 实验测量，属辅助标签允许范围）；DBAASP 的溶血/细胞毒性辅助标签同理。PEER 中的"蛋白+配体 SMILES"输入需要前端支持**残基序列与原子图 token 的拼接共编码**（段嵌入区分），这是统一主干相比纯序列 PLM 的原生优势。

### 2.5 跨域统一架构参照：序列统一与多任务统一各有取舍

把四域塞进一个 Encoder 并非没有先例。**NatureLM**（微软 AI4Science）把 SMILES、FASTA、核苷酸、材料序列与文本统一为 token 序列，用模态分隔符（`<mol>…</mol>` 等）区分，在 1,430 亿 token 上训练 1B/8B/46.7B 三档，跨域生成与设计任务上匹配或超过专用模型（[NatureLM, arXiv:2502.07527](https://arxiv.org/html/2502.07527v3)）。**T5ProtChem** 用 T5 同时吃 PubChem 9,700 万 SMILES 与 UniRef50 5,200 万蛋白序列，并设计了 ProtiSMILES 目标（把被掩氨基酸解码为其 SMILES），证明化学-生物序列可以在同一词表（203 token）里联合预训练（[T5ProtChem, JCIM](https://pubs.acs.org/doi/10.1021/acs.jcim.5c00051)）。**BioMatrix** 在 Qwen3-1.7B 上继续预训练 3,044 亿 token（分子 737 亿、蛋白 774 亿、文本 1,053 亿、跨实体 480 亿），词表扩展了 11,294 个分子 3D token 与 4,096 个蛋白 3D token（[BioMatrix, Hugging Face](https://huggingface.co/QizhiPei/BioMatrix-1.7B-SFT)）。而 UMA/DPA-2 证明了另一条路：**不统一 token，统一"监督信号"（能量/力）与主干，让不同域共用原子级表示**。

**两条统一路线的取舍**对本赛题很关键：纯序列统一（NatureLM 式）实现最简单，但把 3D 构象和周期晶体压成字符串会损失几何信息，而本赛题恰有 3,400 万条 3D 输入和 2,500 万条晶体输入；纯原子统一（UMA 式）几何表达最强，但蛋白/肽是残基级对象，逐残基任务与原子粒度错位。因此本方案采**折中架构：原子级前端与残基级前端并存、共享一个 Transformer 主干**——输入层按域定制（合法），主干与读出全共享（满足"实质同一 Encoder 主体"），这与 NatureLM 的"模态分隔符"思想和 UMA 的"任务条件 MoLE"思想同源。

### 2.6 冻结表征协议的实证证据：预训练目标决定成败

本赛题是罕见的"强制冻结 + 线性探针"竞赛协议，文献中恰好有一组针对性证据。第一，ChemBERTa-2 的对照实验显示，**以回归真实/可计算性质为目标的 MTR 预训练在所有下游任务上优于纯 MLM**（[ChemBERTa-2](https://ar5iv.labs.arxiv.org/html/2209.01712)）；第二，CheMeleon 证明描述符监督能让小模型在冻结/低数据设定下稳定超过随机森林与指纹基线（[CheMeleon](https://arxiv.org/abs/2506.15792)）；第三，多项基准发现纯掩码类分子模型的冻结嵌入经常输给 ECFP+RF（[Lzicar](https://mireklzicar.com/blog/embeddings-fingerprints/)）；第四，PEER 官方确认蛋白 PLM 冻结特征在多数蛋白任务上最强（[PEER](https://neurips.cc/virtual/2022/events/datasets-benchmarks-2022)）。四条证据合起来给出本方案预训练算法设计的第一原则：**自监督重建（掩码/去噪）负责覆盖度与几何理解，显式监督（描述符/能量/力）负责把性质信息写成线性可读形式，二者缺一不可**。

| ChEMBL 结构（仅用结构、不用活性标签） | 约 240 万 | CC-BY-SA（[ChEMBL](https://www.ebi.ac.uk/chembl/)） | 小分子 | 与 QMugs/GEOM 同化学空间，填缝 |
| **PI1M** | 约 100 万 PSMILES（可 5× 增强） | 公开基准（[PI1M, JCIM 2020](https://pubs.acs.org/doi/10.1021/acs.jcim.0c00726)） | 聚合物 | 聚合物域 MLM 主语料（TransPolymer/polyBERT 验证） |
| UniRef50 | 约 5,400 万序列 / 152 亿氨基酸 token | 公开（[UniProt](https://www.uniprot.org/)） | 蛋白/肽 | 蛋白域 MLM 主语料（ESM-2 同源） |

**显式排除项**：不使用任何公开预训练权重（规则一）；不使用 ESM-2/Uni-Mol2/UMA 权重做蒸馏（权重本身违规，其输出作为标签同样构成"未经声明的实质依赖"，风险大于收益）；不爬取任何与 A 榜 90 个性质或 B 榜潜在性质等价的标注数据库（防"测试集等价标签"红线）。

### 4.3 去泄漏与合规审计

预训练语料必须与 A 榜验证/测试集（以及可预见的 B 榜同源物质）隔离，审计流水线如下，且作为复现材料 `data/preprocess/` 的一部分提交：

1. **分子域**：以标准异构 SMILES + InChIKey（第一层）为指纹，对外部语料与官方 A 榜 validation/test 记录做双向查重，命中即剔除外部侧；GEOM/QMugs/QM9/PubChemQC 的官方辅助标签已由主办方保证不含 A 榜 val/test 物质，但仍跑一次哈希校验留证。
2. **聚合物域**：以规范化 PSMILES（参照 polyBERT 的 canonicalize 流程）为指纹查重。
3. **晶体域**：以"约化化学式 + 空间群 + 母分子 InChIKey"三元组查重；OMC25 官方切分本身按起始堆积划分，沿用其训练帧即可。
4. **蛋白域**：对 UniRef50 语料与 CATH/PEER/DBAASP 的 val/test 序列做 k-mer 级快速预筛 + MMseqs2 级同一性复核（≥90% 同一性即剔除语料侧），与 UniRef50 聚类口径天然兼容。
5. **留证**：全部剔除日志、指纹文件 hash、脚本与随机种子写入复现材料；`compliance_statement.md` 逐项声明数据来源、许可与用途。

### 4.4 数据混合与采样策略

多域混合参考两个经过验证的做法。其一，**温度采样压长尾**：Uni-Mol2 用 τ=0.005 的骨架温度采样平衡化学空间长尾（[Uni-Mol2](https://arxiv.org/abs/2406.14969)）；JMP 复现实验显示温度采样与平衡采样在多域预训练中效果差异显著（[JMP 复现](https://openreview.net/pdf/f79a10468057fce63f377283854ecaa22fdde722.pdf)）。本方案按"域 → 数据集 → 骨架/聚类"三级做温度采样，域级初始配比为 小分子 40% / 晶体 25% / 蛋白 20% / 聚合物 15%，再以消融微调。其二，**课程式接入 + 回放**：按 §6 的 S1→S4 顺序逐域接入，接入新域时旧域以 15–30% 比例回放，防止灾难性遗忘；蛋白序列训练参照 compute-optimal 研究的数据配比（UniRef50/S 8.5%、UniRef90/50 19.5%、ColabFold 系 72%）（[arXiv:2411.02142](https://arxiv.org/html/2411.02142v1)），在本方案规模下简化为 UniRef50 单源即可。

**总量与吞吐估算**：预训练可见样本量规划为——序列侧约 1.2 亿条（SMILES 6,000 万 + PSMILES 500 万 + 蛋白 5,400 万），原子-3D 侧约 4,000 万构象（GEOM 3,200 万 + QMugs/QM9/PubChemQC 子采样），晶体侧子采样 600–800 万帧（含力/应力监督）。按 §7 的算力估算，该量级在一台 8×H200 节点上约 10–14 天可完成全课程，留有一周复现余量，符合主办方"一周内完成完整训练"的申报口径。

## 5. 预训练 Mask 算法调研与预训练算法设计

### 5.1 Mask / 破坏-重建算法谱系调研

把"遮住一部分、让模型猜回来"这一族算法按**遮什么、怎么遮、猜什么**三个维度梳理，四域文献中的做法可归为六类：

| 类别 | 代表工作 | 掩码对象与比率 | 预测目标与损失 | 要点 |
|---|---|---|---|---|
| 均匀随机 token MLM | BERT 系、ESM-2、ChemBERTa-2、TransPolymer、polyBERT、MoLFormer | 15%（氨基酸/SMILES/PSMILES token）；80/10/10 替换策略 | 交叉熵 | 最稳的基线；ESM-2 在聚类中心上均匀采样以去冗余（[ESM-2](https://www.biorxiv.org/content/10.1101/2022.07.20.500902v2.full.pdf)） |
| 掩码原子（图级） | Uni-Mol/Uni-Mol2 | 15% 原子类型 | 原子类型交叉熵 | 与坐标去噪联合时，以 50% 概率连带掩掉键/距离特征防止"抄答案"（[Uni-Mol2](https://arxiv.org/abs/2406.14969)） |
| 坐标去噪（连续掩码） | Uni-Mol 系、3D-EMGP、Frad 等 | 全体原子坐标加高斯噪声（多 σ） | 预测噪声/坐标/对距离，L1/L2 | 等价于 score matching，学的正是"把原子推回稳定位置的力"方向；与受力回归是同一物理信号的两种来源（[几何 GNN 综述](https://arxiv.org/html/2403.00485v2)） |
| 结构片段/子图掩码 | GROVER、MGMAE | motif/子图级、高掩码率 | 子图语义分类/重建 | 比随机掩码更贴近化学语义，但实现重、收益依任务不稳（[3D-GSRD 综述](https://www.arxiv.org/pdf/2510.16780v2)） |
| 模态/视图掩码 | Mol-JEPA、GraphMVP、3D Infomax | 掩整个模态视图（保持至少一个可见） | 潜空间预测被掩视图嵌入 + SIGReg 防坍塌；或 2D↔3D 对比 | 不在分子上"动手脚"，而是在表征空间做预测，天然抗增广伪影（[Mol-JEPA](https://arxiv.org/html/2608.22642v4)） |
| **结构语义掩码（肽专用）** | PepLand | 按肽结构选掩码单元：侧链原子（SideChain）或整个片段（Fragment），保留肽键骨架 | 原子/片段类型交叉熵 | **肽键原子占比高，随机掩码退化为送分题**；非天然肽亲和力任务 FragmentMasking SCC 0.767 vs 随机 0.678（[PepLand](https://arxiv.org/abs/2311.04419)） |
| 监督式"伪掩码"（MTR/描述符） | ChemBERTa-2 MTR、CheMeleon | 不遮输入，遮"性质标签" | 回归 200 维 RDKit/Mordred 描述符（均值归一化 MSE） | 冻结探针协议下的最强实证路线（[ChemBERTa-2](https://ar5iv.labs.arxiv.org/html/2209.01712), [CheMeleon](https://arxiv.org/abs/2506.15792)） |

三条可操作的调研结论。第一，**掩码率 15% 是序列域的甜点**，但 3D 域的"掩码"强度由噪声水平 σ 控制，需要多 σ 调度而非单点（本方案 σ 在 0.04–1.0 Å 对数均匀采样并把 σ 作条件嵌入喂入）。第二，**掩码与去噪必须联动防捷径**：Uni-Mol2 的"50% 概率连带掩特征"细节虽小，却是防止模型从距离特征直接反推坐标的必要条件。第三，**掩码单元必须匹配数据的重复结构**：蛋白质域靠 UniRef50 聚类去冗余即可用标准随机掩码（ESM-2），但**肽域不行**——肽键/侧链的重复单元使随机掩码的预测分布严重偏斜，PepLand 的消融证明侧链掩码与片段掩码才是有效任务；本方案因此对肽记录（含 DBAASP 非天然肽）启用结构语义掩码，对小分子/聚合物/蛋白保持标准随机掩码。

### 5.2 本方案的预训练目标函数

总目标为六组损失的加权和（分组与分阶段权重见下图与 §6 课程表）：

$$\mathcal{L}=w_1\mathcal{L}_{\text{MLM}}+w_2\mathcal{L}_{\text{denoise}}+w_3\mathcal{L}_{\text{EFS}}+w_4\mathcal{L}_{\text{MTR}}+w_5\mathcal{L}_{\text{align}}+w_6\mathcal{L}_{\text{aux}}$$

各项定义如下。

**（1）掩码重建 $\mathcal{L}_{\text{MLM}}$**（序列前端 + 原子前端）。对 SMILES/PSMILES/氨基酸序列，随机选 15% token，按 80%/10%/10% 替换为 [MASK]/随机 token/原 token，交叉熵重建；对原子图，掩 15% 原子类型做元素分类。**肽记录（原子级前端的 peptide）启用结构语义掩码**：以残基为单位选块（BulkMasking）、优先掩侧链原子而保留肽键骨架（SideChainMasking）、或整片段掩码（FragmentMasking，片段由"保酰胺键 + BRICS 切大侧链"的 AdaFrag 策略生成），三种按 30/40/30 混合采样（PepLand 消融支持片段与侧链掩码最优）。化学感知 tokenization 参照 TransPolymer（识别原子团与括号结构），聚合物 `*` 位点作为一等公民 token。

**（2）坐标去噪 $\mathcal{L}_{\text{denoise}}$**（凡有 3D 的记录）。采样 $\sigma\sim\text{LogUniform}(0.04,1.0)\,\text{Å}$，坐标加噪 $\tilde{x}=x+\sigma\epsilon$，模型预测 $\hat\epsilon$，损失为 $\lVert\hat\epsilon-\epsilon\rVert^2$（Kabsch 对齐后对坐标也可用 L1，参照 Uni-Mol2 的 $L_{\text{coor}}+L_{\text{dist}}$ 双项）；50% 概率连带掩掉对特征。该损失与受力回归在数学上同源于"对数密度/能量的梯度场"，二者联合有协同。

**（3）能量/力/应力回归 $\mathcal{L}_{\text{EFS}}$**（物理锚定主力）。$\mathcal{L}_{\text{EFS}}=\lambda_E\mathcal{L}_E+\lambda_F\mathcal{L}_F+\lambda_S\mathcal{L}_S$：分子级/晶胞级能量用 z-score 标准化后的 Huber；逐原子力直接预测（非保守头，第一阶段省约 40% 训练时间），$\lambda_F:\lambda_E$ 取 30:1 量级（力为逐原子监督，信号密度高两个数量级，参照 OC20/UMA 惯例）；晶体帧加 virial 应力项。数据源：OMC25 力/应力 2,511 万帧、GEOM 能量 3,231 万构象、QMugs 37 字段、QM9 8 性质、PubChemQC/PCQM4Mv2。收尾阶段可接短窗口保守力微调（$F=-\nabla_x E$，eSEN 两阶段配方）。

**（4）描述符蒸馏 $\mathcal{L}_{\text{MTR}}$**（线性可读性的直接来源）。对每条 SMILES/PSMILES 用 RDKit 预计算约 200 维描述符（含 logP、TPSA、氢键供受体、可旋转键、环系计数等），均值-方差归一化后作为回归目标，宽而浅的读出头挂在主干中部与尾部两处，迫使性质信息分布在多层表征中。零标注成本、零许可风险、零泄漏面（描述符由输入确定计算），是性价比最高的一组损失。

**（5）跨视图对齐 $\mathcal{L}_{\text{align}}$**。同一分子的 SMILES 视图与 3D 构象视图做 InfoNCE（温度 0.07，批内负样本），让纯 SMILES 任务（SM-A-1/2）也能吃到 3D 预训练红利；同分子多构象互为正样本（GEOM 的构象系综天然提供）。

**（6）辅助标签多任务 $\mathcal{L}_{\text{aux}}$**。QMugs/QM9/PubChemQC 的分子级物理量、MegaScale 稳定性、DBAASP 非 MIC 标签组成的多任务回归/分类，任务级 z-score 标准化 + Huber。与（3）的区别在于这些是"性质级"而非"物理场级"监督，更靠近下游形态。

**A 榜标签的混入纪律**：A 榜 90 个性质标签仅以独立任务头、总权重 ≤5% 混入，且只取 train split；其用途是"域锚定"而非提分——B 榜考未见性质，过度贴 A 榜分布会伤害泛化，须以自建的"性质留出影子验证集"监控（见 §7）。

![分阶段损失组合](figs/fig4_loss_mix.png)

### 5.3 关键实现细节与消融优先级

- **异构损失归一化**：所有回归标签用训练集统计量 z-score 标准化，每条损失再除以任务方差（Kendall 不确定性加权的简化版），避免能量（数千 Hartree）吃掉偶极矩（几个 Debye）的梯度。
- **多 σ 调度与条件化**：σ 作为标量条件嵌入注入每个去噪样本，模型共享同一权重服务所有噪声水平。
- **防捷径细节**：去噪时对对特征按 50% 概率掩码；MLM 的 80/10/10 防"复制原 token"捷径；对比学习的负样本按骨架去重。
- **消融预算**：24–30 天窗口内最多做 3–4 组 12 小时级小模型消融，优先级排序：① $\mathcal{L}_{\text{MTR}}$ 开/关（文献与直觉分歧最大）；② A 榜标签混入 0% vs 5%；③ 力:能权重比 10:1 vs 30:1 vs 100:1；④ 对比学习开/关。

## 6. 统一 Encoder 架构设计（符合赛题）

### 6.1 总体架构：四域前端 + 共享主干 + 统一读出

![统一Encoder架构](figs/fig2_architecture.png)

架构遵循"输入按域定制、主干完全共享、读出统一维度"三段式。**这样设计的合规逻辑**：赛规要求一个 Encoder、所有领域同一 D、禁止按数据集/子集/记录分支、禁止不同任务加载实质不同的 Encoder 主体，但允许"同一领域的所有子集使用同一套处理"——因此领域级前端差异合法，主干与读出必须共享且冻结后只有一个 checkpoint。设计上对齐两个已验证范式：NatureLM 的"模态分隔/域嵌入统一进一个 Transformer"（[NatureLM](https://arxiv.org/html/2502.07527v3)）与 UMA 的"单一主干 + 条件化 MoLE 扩容量"（[UMA](https://arxiv.org/abs/2506.23971)）。

### 6.2 域前端规格（同一领域内不分叉）

| 前端 | 输入 | token 化与特征 | 专属组件 |
|---|---|---|---|
| 原子级前端（小分子） | SMILES（必选）+ 3D 构象（有则用） | 原子 token：元素、度数、形式电荷、杂化、芳香性、手性标记；对特征：键类型、最短路、高斯基展开欧氏距离 → 作为注意力偏置（双轨简化版） | 无 3D 时退化为图模式，坐标通道置缺失掩码 |
| 聚合物前端 | PSMILES / 单体 SMILES + 组成比 | 复用原子级特征化（RDKit 解析 `*` 为 dummy 原子 token）；共聚物：各单体单元表征按组成比加权融合于前端内部 | 重复单元边界 token；组成比例标量嵌入 |
| 晶体前端 | 周期结构（CIF/ASE 对象） | PBC 图构建：多晶胞扩展 + 截断半径邻居搜索，对特征增加平移向量通道；晶胞参数与空间群嵌入作为全局 token | 周期性对特征编码；力/应力监督仅训练期使用 |
| 序列前端（蛋白/肽） | 氨基酸序列 / 序列对 / 蛋白+配体 | 26–30 词表残基 token + RoPE；序列对用段嵌入拼接；蛋白+配体任务中配体走原子级 token、与残基 token 拼接共编码 | **保留逐 token 输出通路**（逐残基任务）；**非天然肽降级通路：无法残基化的肽（HELM/修饰残基）转 SMILES 走原子级前端**，域嵌入仍为 bio |

所有前端把输入映射到同一维度的 token 序列与对偏置矩阵，随后加上**域嵌入 + 模态嵌入**（小分子/聚合物/晶体/蛋白 × 1D/3D），进入共享主干。每条记录的表征只取决于该记录输入——无批次统计、无跨记录操作，天然满足"批次无关"要求。

### 6.3 共享主干与参数量预算

- **主干**：pre-norm Transformer，24 层、hidden 1024、16 头、FFN 4096，几何感知自注意力（对特征作为加性注意力偏置，逐层更新对表征的轻量版双轨设计），总参数约 **2.5–3 亿**。
- **MoLE 专家层**：FFN 的线性层替换为 8 专家 MoLE，门控条件为域嵌入（可学习软路由，非硬分支——仍是同一网络、同一权重文件，规避"实质不同主体"风险）；参照 UMA，总参数增至约 4 亿而激活量基本不变。
- **条件嵌入**：电荷/自旋（QMugs/GEOM 记录带相应字段时）、温度/测量条件（DBAASP 的 `measurement conditions`）以标量嵌入注入，参照 UMA 的条件化设计与 TransPolymer 把温度当描述符 token 的做法。
- **读出**：默认 [CLS] token 与 mean-pool 拼接 → 线性投影到 **D=1024**；另提供 **GRU 池化候选**（PepLand 消融显示 GRU 池化在全部肽下游任务上优于 mean/max，非天然 CPP Spearman 0.742——对肽这类长度短、全局模式强的对象更友好），由配置开关选择并在 S5 看板上 A/B 验证后锁定其一。L2 之前的原始向量即最终表征（标准化若有需要，作为 Encoder 内部固定仿射折入，合规）；逐残基任务同时输出 `tokens.npy` 通路。
- **MLP 接口核对**：D=1024、隐藏 48 时回归头约 49.3K 参数（1024×48+48+48×1+1），多分类（CATH 各级）与逐残基头亦在 100K 上限内。

### 6.4 课程式预训练计划（对齐赛程）

![课程式推进计划](figs/fig3_curriculum.png)

| 阶段 | 内容 | 数据 | 退出标准 |
|---|---|---|---|
| S0 | 数据管线、清洗、去泄漏审计、tokenizer 训练 | 全部 | 审计报告 + 单位基准（ECFP/随机序列 baseline）出分 |
| S1 | 序列域预训练：MLM + MTR（描述符）；**肽子域两步课程：先天然肽（UniProt ≤50 残基子集）收敛、再续训非天然肽（PepLand 配方）** | PubChem/ZINC、PI1M、UniRef50、CycPeptMPDB 结构（仅作无标签输入） | SMILES/PSMILES/蛋白探针基线分 |
| S2 | 原子-3D 域：掩码原子 + 去噪 + GEOM/QMugs 能量 + 2D↔3D 对齐 | external_inputs 构象 + 辅助标签 | SM-A-3/4/5 探针显著超 S0 基线 |
| S3 | 晶体域：PBC 前端 + OMC25 能量/力/应力（先直接力后短保守微调） | OMC25 子采样帧 | OC-A-1、PO-A-4 探针出分 |
| S4 | 全域联合退火：四域混采（域配比 40/25/20/15）+ 旧域回放 15–30% + A 榜标签 ≤5% 轻量混入 | 全部 | **回归看板**：各域分数相对接入前波动 <1 个点 |
| S5 | 贯穿全程的 A 榜探针回归看板与消融 | A 榜 train/val | 每次训练后自动出 13 数据集分数表 |

**验收门机制**：固定探针协议（种子、轮数、早停全锁死）+ 固定验证切片，任何一次续训后跑看板；新域先出基线分、确认旧域不掉点，再追新域好分。B 榜泛化用"性质留出影子集"模拟：预训练中故意留出若干类辅助标签性质（如偶极矩、某类 ADMET），观察冻结表征在这些留出性质上的探针表现，作为 B 榜行为的代理指标。

## 7. 算力估算、风险与备选降级路线

**算力估算**（申报口径：一台 8×H200 节点、约 2 周）。经验参照：MoLFormer 用线性注意力把 11 亿分子训练压到 16 卡级（[MoLFormer](https://hunterheidenreich.com/notes/chemistry/molecular-representations/encoders/molformer/)）；本方案主干 3 亿参数、序列长度 ≤512（SMILES/PSMILES/蛋白截断），bf16 + FlashAttention + 序列打包，单步吞吐约 6–8 万 token/卡·秒，序列域约 300 亿 token ≈ 5–6 天；原子-3D 域 4,000 万构象 ×3 epoch ≈ 2–3 天；晶体域 700 万帧（直接力阶段）≈ 2–3 天；联合退火 ≈ 2 天。合计 11–14 天，与 S0–S5 课程表一致。B 榜推理侧：2,500 万晶体 + 3,200 万构象全量编码按 8 卡、约 2,000 条/秒/卡估算约 1 小时级，无吞吐风险。

**风险登记册（Top 5）**。① 从零训练 3 亿参数主干在小数据蛋白质域欠拟合 → 缓解：蛋白域数据量最大（152 亿 token），且 MoLE 提供域容量；降级：主干缩至 150M。② 晶体前端工程延期 → 缓解：S3 与 S1/S2 并行，PBC 图构建第一天就立项；降级：晶体域退化为"组成 + 局部环境"无 PBC 表征保基线分。③ 描述符蒸馏在小分子域收益不及预期 → 消融①在 W2 给出结论，关闭即省 30% 序列域算力。④ A 榜标签混入伤害 B 榜泛化 → 影子留出集监控，权重从 5% 降至 0 的回退预案预先写好。⑤ 复现环境差异 → 每周一次干净环境端到端演练（encode → mlp_infer → score），Docker digest 从第一周起冻结管理。

**与赛题叙事的契合**：本方案把赛题名称里的两个关键词落到了具体机制上——"统一表征"由共享主干 + 统一 D + 跨视图对齐实现；"多尺度融合"由原子级/残基级前端、分子级与逐原子级监督、能量场与性质双层标签体系实现。若进入答辩，UMA（跨域 MoLE 迁移）与 CheMeleon（描述符监督的冻结探针优势）两篇文献是技术叙事的最佳支点。
