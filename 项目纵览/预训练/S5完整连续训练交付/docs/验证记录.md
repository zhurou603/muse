## 3. 验证中发现并修复的问题

1. **独立包直接运行单测缺少原项目模块**：这是增量包依赖路径问题；加入原项目 `code/model_design` 后正常。README 已明确安装和运行依赖。
2. **resume 血缘记录报错**：底层 `Trainer.resume()` 更新内部状态但不返回状态，S5 原实现误读返回值，导致写 `resumed_from.json` 时出现 `AttributeError`。已改为读取恢复后的 `self.state`，新增 checkpoint/latest/resume 回归测试并通过。
3. **bootstrap 可能覆盖已有最佳的风险**：已增加显式拒绝逻辑和单测，已有 best_fixed 时不能再次用 `--bootstrap` 覆盖。
4. **DDP checkpoint 发布时机**：已在写 `latest.json` 前增加 rank barrier，确保各 rank RNG sidecar 均写完后再发布恢复指针。
5. **多种子探针集成的 MLP 合规风险**：分类 sigmoid/softmax 后的多模型平均不能等价合并为一个两层 MLP，四种子回归头合并也会超过 100,000 参数。S5 看板已改为每任务固定单种子、单个两层 MLP，新增实际训练调用次数和参数预算测试。旧集成看板结果不与新协议直接比较。
